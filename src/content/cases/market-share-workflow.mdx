      }
    </p>

  <section id="approach">
    <p class="eyebrow">{'02 / Analytical approach'}</p>
    <h2>{'Prove the method manually, then make it repeatable'}</h2>
    <p>
      {
        'The first phase established the analytical method. I used targeted product reviews to define the comparison grain, remove duplicate competitor records before aggregation, reconcile selected source and output totals, and document attributes that were missing, malformed, or open to interpretation.'
      }
    </p>
    <p>
      {
        'I then converted the validated steps into a configurable Python and SQL workflow. It profiled source coverage and normalized evidence, applied reviewed comparison rules, generated controlled analysis outputs, and preserved review questions instead of turning proposed treatments into accepted business rules.'
      }
    </p>
    <ol>
      <li>
        <strong>{'Data readiness.'}</strong>
        {
          ' Check whether the selected population, reporting periods, sales coverage, parsing, and classification are sufficient to begin.'
        }
      </li>
      <li>
        <strong>{'Rule readiness.'}</strong>
        {
          ' Distinguish active rules from proposals and keep uncertain product meaning outside a final result until the responsible stakeholders review it.'
        }
      </li>
      <li>
        <strong>{'Output validation.'}</strong>
        {
          ' Reconcile source and output totals, inspect assignments and exceptions, and prevent an incomplete or failed run from replacing an accepted result.'
        }
      </li>
    </ol>
    <p>
      {
        'These controls allowed an analysis to remain a clearly identified draft, stop when no safe comparison was available, or move forward as final when the evidence and rule authority were sufficient. Technical corrections followed controlled checks; business acceptance remained a human decision.'
      }
    </p>
    <h3>{'A review application for business and technical users'}</h3>
    <p>
      {
        'I built a five-page Streamlit application that brought run status, market-share summaries, opportunity review, product drill-down, and validation evidence into one review experience. Filters, traceable definitions, exception views, and exports helped reviewers move from a summary result to the evidence behind it without changing the underlying analytical rules.'
      }
    </p>
